Data files of the planner

The atlas pages load data files from the atlas data folder; the same values are in the downloads below. Each file has a description of its fields as a JSON schema in the repository. Calculated on 13 November 2026.

  • haltestellen.js: stops with frequency class, without district assignment (CC BY 4.0, ZTP).
  • einrichtungen.js: schools, kindergartens, nurseries, hospitals and parks from BDOT10k, without district assignment.
  • einrichtungen_odbl.js: doctors and pharmacies from OpenStreetMap, without names (ODbL).
  • erreichbar.js: straight-line distance from the centre of each cell to the nearest facility.
  • erreichbar_fuss_odbl.js: the same as a walking route along the OpenStreetMap path network (ODbL).
  • planer_odbl.js, planer_fuss_odbl.js: indicators by district and for the whole city with numerator and denominator, as straight line and walking route (ODbL, because the assignment uses the OpenStreetMap boundaries).

Downloads

  • kiezatlas_krakow.gpkg: layers siatka_1km (residents and straight-line distances), placowki_bdot, przystanki.
  • kiezatlas_krakow_odbl.gpkg (ODbL 1.0): layers siatka_1km_odbl (with district and walking route), dostepnosc (indicators by district), placowki_osm, dzielnice.
  • kiezatlas_krakow_csv.zip: the same layers as CSV; in csv_pl/ with a decimal comma for Polish-locale Excel.
  • licencje.csv: licence and source notice for every layer.
