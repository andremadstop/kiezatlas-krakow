Data files of the topic

The atlas pages load data files from the atlas data folder; the same values are in the downloads below. Each file has a description of its fields as a JSON schema in the repository.

  • gebaeude_kennzahlen.js: buildings of the city and the four delegatury from BDOT10k (number, use, storeys, footprint) with the origin of heights; data as of [[gebaeude_kennzahlen:stand_daten|datum]].
  • gebaeude_dzielnice_odbl.js: the same indicators by district (ODbL, because the assignment uses the OpenStreetMap boundaries).
  • denkmale_bdot.js: counts of multi-family buildings, complexes and buildings named “Kamienica …” from BDOT10k.
    • [[wenn denkmale_odbl:sichtpruefung.geprueft]]
  • denkmale_odbl.js: OpenStreetMap objects with heritage or start_date; location of the objects tagged heritage checked on the orthophoto for a random sample (n = [[denkmale_odbl:sichtpruefung.ergebnis.n]], [[denkmale_odbl:sichtpruefung.datum|datum]]): on the object [[denkmale_odbl:sichtpruefung.ergebnis.lage.ja]], just beside it [[denkmale_odbl:sichtpruefung.ergebnis.lage.daneben]], away from it [[denkmale_odbl:sichtpruefung.ergebnis.lage.nein]], i.e. [[denkmale_odbl:sichtpruefung.ergebnis.lage.quote|anteil0]] on the object (Wilson 95% interval [[denkmale_odbl:sichtpruefung.ergebnis.lage.wilson95.0|anteil0]]–[[denkmale_odbl:sichtpruefung.ergebnis.lage.wilson95.1|anteil0]]), not for every single point (ODbL); as of [[denkmale_odbl:stand|datum]].
    • [[sonst]]
  • denkmale_odbl.js: OpenStreetMap objects with heritage or start_date, location unchecked (ODbL); as of [[denkmale_odbl:stand|datum]].
    • [[ende]] [[wenn denkmale:sichtpruefung.geprueft]]
  • denkmale.js: register of monuments, so far only the Wikidata part ([[denkmale:quellen.wd.vermerk|text]], as of [[denkmale:stand|datum]]): per point period of construction, residential use, multi-family building and delegatura, without identifiers and without names; location checked on the orthophoto for a random sample (n = [[denkmale:sichtpruefung.ergebnis.n]], [[denkmale:sichtpruefung.datum|datum]]): on the object [[denkmale:sichtpruefung.ergebnis.lage.ja]], just beside it [[denkmale:sichtpruefung.ergebnis.lage.daneben]], away from it [[denkmale:sichtpruefung.ergebnis.lage.nein]], i.e. [[denkmale:sichtpruefung.ergebnis.lage.quote|anteil0]] on the object (Wilson 95% interval [[denkmale:sichtpruefung.ergebnis.lage.wilson95.0|anteil0]]–[[denkmale:sichtpruefung.ergebnis.lage.wilson95.1|anteil0]]), not for every single point. The NID register and the gminna ewidencja zabytków are missing (manual download outstanding).
    • [[sonst]]
  • denkmale.js: register of monuments, so far only the Wikidata part ([[denkmale:quellen.wd.vermerk|text]], as of [[denkmale:stand|datum]]): per point period of construction, residential use, multi-family building and delegatura, without identifiers and without names; location not checked. The NID register and the gminna ewidencja zabytków are missing (manual download outstanding).
    • [[ende]]
  • sanierung.js: the ZBK list by type, ownership and district as listed, and the block typology by delegatura; list as of [[sanierung:stand|datum]].
  • sanierung_odbl.js: locations of ZBK buildings in public ownership and the typology by district (ODbL, because the addresses were looked up in OpenStreetMap).

The building bodies for the 3D view (one file per district, ODbL) are kept outside the repository; the page loads them only when the 3D view is switched on. They are not part of the downloads.

Downloads

  • kiezatlas_krakow.gpkg: layers miasto, delegatury, bdot_kompleksy, bdot_kamienica_nazwa, zbk_wykaz_dzielnice.
  • kiezatlas_krakow_odbl.gpkg (ODbL 1.0): layers dzielnice, osm_heritage_start_date, zbk_budynki, zbk_typologia_dzielnice.
  • kiezatlas_krakow_csv.zip: the same layers as CSV; in csv_pl/ with a decimal comma for Polish-locale Excel.
  • licencje.csv: licence and source notice for every layer.
